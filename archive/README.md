# 작품 제출 양식

이 폴더의 예시를 실제 작품의 JSON과 이미지로 교체하세요. 제출 위치는 `woowangthon/hub`의 본인 팀 브랜치입니다.

- 팀 브랜치: `W01`~`W51`. 팀 번호는 두 자리이며 이름을 덧붙이지 않습니다.
- JSON: `archive/archive.json`. 파일명과 필드 대소문자를 지킵니다.
- `demoUrl`만 선택입니다. 서비스가 없으면 `""` 또는 항목 생략을 허용합니다.
- 나머지 모든 필드와 배열은 필수입니다. 팀원도 최소 1명, 담당 역할도 최소 1개입니다.
- `teamNumber`는 숫자입니다. `W01`은 `1`, `W32`는 `32`입니다.
- `repositoryUrl`은 작품 소스가 있는 대표 GitHub 저장소의 HTTPS 주소입니다. 이 hub 저장소와 같을 필요가 없습니다.
- `demoVideoUrl`은 공개 재생 가능한 HTTPS 영상 주소입니다. 영상 파일을 다시 제출할 필요가 없습니다.
- `thumbnail`과 `screenshots`는 이 JSON을 기준으로 한 상대 경로입니다. 예: `thumbnail.png`, `screenshots/screen-1.png`.
- 이미지: 정적 PNG/JPEG/WebP, 파일당 20MiB 이하·40메가픽셀 이하. 팀 폴더 전체는 100MiB 이하, JSON은 100KiB 이하입니다. 특정 가로세로 비율이나 최소 글자 수는 강제하지 않습니다.
- 이미지의 실제 형식과 확장자가 같아야 합니다. 외부 이미지 주소, `../`, 심볼릭 링크, 서브모듈, 실행 파일은 허용하지 않습니다.
- `members`: `name`(이름), `roles`(담당 역할 배열), `contribution`(기여 내용). 추가 개인정보는 받지 않습니다.
- `techHighlights`는 기술적 특징입니다. 1~3개를 권장하며 긴 보고서를 요구하지 않습니다.

푸시 후 GitHub Actions의 **전시회 자동 배포 → 제출 JSON·이미지 검사**에서 결과를 확인합니다. 실패하면 표시된 필드·경로를 수정하고 다시 푸시하세요. 기존 팀 브랜치는 main의 워크플로 변경을 자동으로 받지 않으므로 운영진의 안내를 따릅니다.

수집 시에도 독립적으로 다시 검사합니다. 정상 제출은 매일 한국 시간 00:10에 시작하는 배포에 반영되며 GitHub 실행 상황에 따라 지연될 수 있습니다. 미제출 예시는 전시하지 않습니다. 잘못된 제출 자료가 있으면 새 배포가 보류되고 기존 공개 사이트가 유지됩니다.
