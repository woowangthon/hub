# 우왕톤 아카이빙 프로젝트 제출

1. `main`에서 본인 팀의 브랜치를 만드세요.
   - 브랜치 이름: `W01`~`W51`
   - 예: 1팀은 `W01`, 32팀은 `W32`
2. [제출 양식](archive/README.md)을 읽고 `archive.example.json`의 내용을 빈 `archive.json`에 복사한 뒤 우리 팀의 정보로 수정하세요.
3. 대표 이미지와 추가 화면을 `archive/`에 넣고, 본인 팀 브랜치에 커밋·푸시하세요. PR이나 main으로의 머지는 필요 없습니다.
4. GitHub Actions에서 제출 검사 결과를 확인하세요. 오류가 있으면 수정 후 다시 푸시하세요.

```text
archive/
├─ README.md
├─ archive.json          # 여기에 실제 제출 내용을 작성
├─ archive.example.json  # 작성 참고용 예시
└─ screenshots/          # 추가 화면 이미지를 넣을 폴더
```

- 이미지는 직접 추가해야 합니다. 대표 이미지는 `archive/`, 추가 화면은 `archive/screenshots/`에 넣으세요.
- 참가자는 `archive/` 안의 제출 자료만 수정하세요.
