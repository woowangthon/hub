# 우왕톤 아카이브 페이지

- AI 우왕톤의 행사 소개와 참가 프로젝트를 보여주는 웹사이트입니다.
- 참가자 제출 안내와 예시는 `main` 브랜치에서 확인하세요.

## 프로젝트 데이터

- 수집 설정: `config/archive.json`
- 제출 규격: `schemas/archive.schema.json`
- 수집 완료 후 게시용 빌드: `pnpm build:archive`
- GitHub Pages 게시 파일: `dist/`

## 라이선스

- 사용한 폰트·아이콘·공통 컴포넌트의 라이선스는 `public/licenses/`에 있습니다.
- 기관·행사 로고의 권리는 각 권리자에게 있습니다.
